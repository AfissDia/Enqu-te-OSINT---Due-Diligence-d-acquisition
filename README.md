# NovaTech Defense - Due Diligence OSINT

Projet académique de due diligence réputationnelle et cyber sur une **entreprise fictive**.

## Objectif
Évaluer, à partir de sources ouvertes et légales, les risques pouvant influencer une décision d'acquisition : gouvernance, actionnariat, litiges, exposition cyber, conformité apparente et réputation.

## Périmètre fictif
- Société : NovaTech Defense SAS
- Localisation : Toulouse, France
- Création : 2012
- Effectif : ~120 salariés
- Secteur : défense, systèmes embarqués et communications sécurisées
- Valorisation de l'opération : 42 M€

## Règles
- aucune intrusion ;
- aucune ingénierie sociale active ;
- collecte passive et légale ;
- outils open source uniquement ;
- résultats reproductibles ;
- données et identités du scénario fictives.

## Structure
- `docs/` : rapport, méthodologie, scénario et OPSEC
- `investigation/` : timeline, sources et findings
- `evidence/` : preuves classées par thème
- `maps/` : cartographie de l'écosystème
- `scripts/` : scripts reproductibles
