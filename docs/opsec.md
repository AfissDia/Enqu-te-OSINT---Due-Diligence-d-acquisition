# Note OPSEC

## Objectif
Limiter les traces inutiles pendant l'enquête et éviter tout contact direct avec la cible fictive.

## Mesures retenues
- environnement de travail dédié ;
- aucun compte personnel utilisé pour l'enquête ;
- aucune interaction directe avec des employés ;
- aucune tentative d'authentification ;
- aucune exploitation de service ou vulnérabilité ;
- collecte limitée aux sources ouvertes ;
- conservation locale des preuves nécessaires ;
- suppression ou masquage de toute donnée qui ne doit pas être publiée dans le dépôt public.

## Limite importante
Le projet vise la due diligence OSINT et non le pentest. Une exposition observée est documentée sans chercher à l'exploiter.
